# 数独 · 用户指南

一个打开就能玩的网页版数独。不用注册，不用下载，数据只存在你自己的浏览器里。

---

## 怎么打开

在浏览器地址栏输入网址即可（把下面换成实际部署的地址）：

```
https://你的网址
```

手机上还可以「添加到主屏幕」，之后像 App 一样从桌面图标打开：

- **iPhone / iPad**：Safari 打开 → 底部分享按钮 → 「添加到主屏幕」
- **Android**：Chrome 打开 → 右上角菜单 → 「安装应用」或「添加到主屏幕」

> 需要联网打开。断网时打不开，这一点和普通网页一样。

---

## 开始一局

打开首页，五个难度任选一个，直接进入棋盘。

| 难度 | 需要什么技巧 | 大概用时 |
|---|---|---|
| 入门 | 唯一余数、基础排除 | 3–8 分钟 |
| 简单 | 区块排除、数对 | 5–15 分钟 |
| 中等 | 三数集、X-Wing、XY-Wing | 10–25 分钟 |
| 困难 | 唯一矩形、剑鱼、简单链 | 20–45 分钟 |
| 专家 | 高级链、强制链，可能需要试错 | 30–90 分钟 |

上次没下完的对局会自动保存，下次打开首页会看到「继续上一局」。

---

## 怎么填数

1. 点一个空格选中它
2. 点下方数字键盘，或者按键盘上的 `1`–`9`
3. 填错了再点别的数字覆盖，或者按 `⌫` 清除

**颜色含义**：

- 深色粗体数字 = 题目给定的，不能改
- 蓝色数字 = 你自己填的
- 红色背景 + 感叹号 = 和同一行/列/宫里的数字重复了

棋盘填满后会自动判定。全对就完成，有错会标出错的格子，改掉就行。

---

## 候选数（小数字标记）

不确定填什么时，可以先把候选数字记在格子里：

1. 点右下角的「候选」按钮（或按 `N`）切换到候选模式
2. 点格子，再点数字，就会记上一个小数字
3. 再点一次同一个数字可以取消

填入确定数字时，同行、同列、同宫的相同候选会自动清掉（可以在设置里关掉）。

---

## 卡住了怎么办

对局页有「撤销」「重做」「求解本题」三个按钮。

- **撤销 / 重做**：误操作可以回退
- **求解本题**：直接看完整答案

求解后这局会标记为「机器求解」，**不计入完成率和最佳时间**，但可以随时「重置本题」再来。

---

## 键盘操作

如果你在电脑上玩，用键盘比点鼠标快：

| 按键 | 作用 |
|---|---|
| `↑` `↓` `←` `→` | 移动选中的格子 |
| `1`–`9` | 填入数字 |
| `N` | 切换候选模式 |
| `⌫` 或 `Delete` | 清除当前格 |

---

## 自己录入题目

首页 →「自定义题目」，三种方式：

1. **粘贴**：把 81 位题目粘进去（`0`、`.`、`_` 都代表空格）
2. **逐格录入**：像玩一样把题目摆出来
3. **从文件导入**：支持 `.txt`（每行一道题）和 `.json`

录入后点「校验题目」，系统会依次检查格式、冲突、提示数、有没有解、是不是唯一解。全部通过才能开始。

> 有多解的题目会被拒绝——标准数独要求唯一解。想算答案可以用下面的求解器。

---

## 求解任意题目

首页 →「独立求解器」。粘贴题目，会告诉你：

- 有唯一解（并给出答案）
- 有多个解（给一个解并提醒）
- 无解
- 有冲突（指出具体哪一格）

---

## 收藏

玩完一局后，结果页可以点「收藏本题」。收藏的题会出现在首页的「收藏」里。

收藏列表支持：

- 按标题或标签**搜索**
- 按难度、完成状态**筛选**
- 按收藏时间、最近游玩、难度、最佳用时**排序**
- 点「编辑」改标题、加标签、写备注

删错了别慌，5 秒内可以「撤销」。

---

## 统计

首页 →「统计」，看：

- 玩了多少局、完成多少、完成率
- 每个难度的完成数、最佳用时、平均用时
- 连续玩了多少天

点「重置统计」可以清零，**不影响收藏和进行中的对局**。

---

## 设置

- **主题**：跟随系统 / 浅色 / 深色
- **候选数自动清理**：填入数字后是否自动清掉相关候选
- **高亮**：是否高亮同行列宫、相同数字
- **冲突提示**：是否实时标红重复数字
- **计时器**：是否在状态栏显示用时
- **暂停遮挡**：暂停时是否遮住棋盘
- **减少动态效果**：关掉动画和过渡

所有设置改完立即生效，不用保存。

---

## 数据安全（重要，请务必看一下）

**你的所有数据——对局进度、收藏、统计、设置——只存在这台设备的这个浏览器里。**

- 不需要注册，也不会上传到任何地方
- 换浏览器、换设备、清理浏览器数据，数据就没了，找不回来

**想保住数据，请定期导出备份：**

设置页 →「备份」→「导出备份」，会下载一个 JSON 文件。

换设备或重装浏览器后，在新设备的设置页点「选择备份文件导入」即可恢复。

> 建议每次玩了一段时间就导出一份，存到网盘或发给自己。

## 常见问题

**Q：打不开页面 / 一片空白？**
尝试换个浏览器（Chrome、Edge、Safari、Firefox 都支持），或检查网络。

**Q：数据丢了怎么办？**
如果有备份文件，在设置页导入即可。没有备份的话，浏览器清理过的数据无法恢复。

**Q：能离线玩吗？**
不能。每次打开需要联网加载页面。

**Q：能换成别的语言吗？**
目前只有简体中文。

**Q：两个标签页同时开同一局会怎样？**
以最后操作的那个标签页为准，另一个的修改会被覆盖。建议只开一个标签页玩。

**Q：填满了但没反应？**
说明有填错的格子，会被标红，改掉即可。如果全部正确，会直接判定完成。

**Q：有没有提示功能？**
没有。卡住的话可以用「撤销」回退，或者「求解本题」看答案（这局不计入成绩）。
