### AC-10 离线游玩（已取消）

**状态**：🚫 需求取消（SRS V1.3）

- 取消原因：单人自用项目，离线能力的实现与维护成本高于收益；手写 SW 在 Playwright 下难以稳定验证（每次盲改要用户跑 3–4 分钟）。
- 已移除：`public/sw.js`、构建期预缓存清单插件、全部离线用例。
- 保留：`manifest.webmanifest` 与图标，「添加到主屏幕」仍可用；`src/main.tsx` 保留注销旧 SW 的逻辑，避免历史缓存导致更新不生效。
- 仍有用例：`pwa.spec.ts` 覆盖 manifest 内容、图标可访问、以及「不再注册 SW」。

### AC-11 备份导入导出

**状态**：✅ 自动化覆盖

- `src/storage/backup.ts`：导出全部数据为 JSON；导入前逐条校验 format / version / 字段 / 81 位格式。
- 导入在单个 Dexie 事务里执行，失败自动回滚（FR-DAT-006）。
- 支持合并（按 id 去重、保留较新记录并统计冲突）与替换两种模式。
- 单测 11 例（往返、replace 清空、merge 冲突、坏文件拒绝）；E2E 3 例（导出文件名、往返导入、损坏文件与非本应用备份被拒）。

### AC-12 响应式与无障碍

**状态**：⚠️ 语义与键盘已覆盖，布局待真机

- **axe 扫描 0 serious/critical**：7 个页面（首页、对局、自定义、求解器、收藏、设置、关于），见 `e2e/a11y.spec.ts`。
- 键盘完整操作有 E2E（方向键、数字键、N、退格）。
- 只读棋盘暴露 `aria-readonly`，屏幕阅读器可读出只读状态。
- **待真机**：200% 缩放、320px 重排没有自动化验证（axe 只查语义，不查布局）。

### AC-13 性能

**状态**：⚠️ 引擎层已测，浏览器侧待真机

- 引擎层有完整数据：`docs/PERFORMANCE.md`（`pnpm perf` 复现）。取题 P95 ≤ 0.74 ms、求解 P95 ≤ 0.48 ms，均远低于要求。
- 关键发现：专家档评级 P95 达 933 ms，题库化后该开销已移出运行时。
- **待真机**：Lighthouse 首屏、30 局内存曲线、落子交互延迟——清单见 `docs/PERFORMANCE.md` 第 5 节。

### AC-14 多标签页（已取消）

**状态**：🚫 需求取消（SRS V1.5）

- 取消原因：实现存在卸载与重建的时序竞态——`puzzleId` 变化时重建 coordinator，而 Web Lock 的释放是异步的，浏览器回退/前进会在旧锁释放前重新 `acquire`，拿到 `null` 被误判为「第二个标签页」，把自己锁成只读。
- 已移除：`storage/multitab.ts` 与其 7 例单测、`e2e/multitab.spec.ts`、`GamePage` 的锁与只读 UI、`BoardGrid` 的 `readOnly`/`aria-readonly`。
- 现状：同一对局在两个标签页打开时，以最后一次写入为准。单人自用场景数据覆盖风险可接受。

### AC-15 隐私

**状态**：✅ 可静态验证

- 零网络请求：没有分析脚本、没有外部字体、没有错误上报。
- 可用 `page.on("request")` 断言除同源资源外没有出站请求。
